## Verdict

**Original README: materially incomplete as a standalone handoff**, despite broad and useful command coverage. It did not identify the exact commit/comparison base or distinguish untracked local functionality from clone contents. It omitted essential feature construction, identity/matching rules, exclusions, clustering acceptance, and gesture evaluation setup, and understated geometry and provenance incompatibilities.

**Revised README: mostly complete for scientific orientation and choosing documented workflows.** It preserves the professor-facing graph guide and practical recipes, adds the missing methodological context, and bounds claims by actual evidence. It cannot be a self-contained reproduction package or allow arbitrary code changes without code/data: major inputs are ignored, annotation sources are absent, local functionality is untracked, outputs generally lack revision/input hashes, and runtime success remains untested. These are explicit remaining limits, not claims that everything is covered.

## Incorrect, unsupported, or insufficiently qualified claims

1. **?Self-contained handoff? was too strong.** Missing annotations, ignored decoded data, local-only code/results and absent revision provenance prevent reproduction from README alone or from a clone alone. Opening sentence and snapshot now qualify this.
2. **Entry review was described as potentially evaluating current potential zones.** Its source implements circles only, accessing `radius_m`; current rectangles are incompatible. F now limits the example to 3/7/15/21 and states the failure mode.
3. **?Original scenario time? was imprecise.** Class-derived trajectory time is shifted to first usable zero; graph description now calls it elapsed time. Onset, conflict anchors and normalized progress are separately explained.
4. **?Closing speed? suggested m/s.** Reusable negative distance difference is not divided by dt; the expanded feature retains a misleading name. README now distinguishes this from conflict-analysis derivative closing speed. No code/output was altered.
5. **?CHI poster feasibility? implied a documented plan.** No explicit plan was found. README now labels candidate poster directions as a synthesis of implemented capabilities, with no invented prior decision.
6. **?Verified encounter? needed a scope.** Current decoded SHA matches saved presentation verification and image footers; this establishes source identity, not raw/video correspondence, annotation match, or global output freshness. The heading now says source-matched.
7. **Clustering stability terminology and success claims needed criteria.** Saved `bootstrap_ari` fields use without-replacement subsampling in scenario-specific code. General and scenario methods/thresholds differ. Acceptable paths only in 3/12, rejected response/pooled solutions, and fallback exploratory assignments are explicitly separated.
8. **Postprocessing was underspecified.** It changes exclusions and writes some outputs that full run does not; current code cannot justify treating both invocations as identical. Saved configuration does not settle invocation provenance.
9. **Saved verification JSON is not proof of scientific validity or current execution.** Full-run `no_silent_zero_imputation` checks count ?0; some other flags only establish presence/IDs. README explains this, and no saved ?true? was presented as a newly passed test.
10. **Gesture interpretation lacked class imbalance and false positives.** Saved rule positive precision 0.231 / recall 0.840 explains why balanced accuracy 0.610 is not a useful validated detector. Learned-model confidence intervals span 0.5; usefulness/context benefit remain inconclusive, not proof the information is inherently unusable.

Already accurate practical caveats were retained: openpyxl missing from requirements, unpinned versions, local Python/encoder environment, ambiguous Scenario 3 discovery, wrapper overwrites, ignored interactive `--input`, fixed skeleton inputs, creation refusing existing presentation folder, and verifiers writing QA images. No documented CLI flag discrepancy was found beyond those already noted. Commands were inspected/parsed, not successfully executed.
